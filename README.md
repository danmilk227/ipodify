# iPodify

iPodify — это стилизованный веб-клиент и PWA-плеер для Spotify с управлением через виртуальное колесо **Click Wheel**[cite: 6, 8]. Проект сочетает аутентичную механику классического iPod 1-го поколения и модульную систему тем оформления, включая современную тему **iOS 26 (Liquid Glass)** с оптическим преломлением жидкого стекла и обложками альбомов.

---

## Основные возможности

### Сменные темы интерфейса (`Settings -> Theme`)
- **Classic 1G**: Аутентичный монохромный LCD-экран с подсветкой (Backlight), пиксельной эстетикой и классическим корпусом iPod 2001 года[cite: 6, 8, 10].
- **iOS 26 Glass**: Дизайн в стиле жидкого стекла (Liquid Glass) с оптическим SVG-преломлением фона, хроматическими бликами на гранях, отображением обложки текущего трека, радужным прогресс-баром и динамическим фоновым свечением.
- **Модульная архитектура тем**: Все темы лежат в `src/public/themes/` и подключаются через `registry.js`.

### Аутентичное управление и детали
- **Click Wheel**: Круговая сенсорная и мышиная прокрутка, поддержка управления с клавиатуры (`Стрелки`, `Enter`, `Backspace`/`Esc`, `Пробел`)[cite: 6, 8].
- **Пьезо-щелчки (Piezo Clicker)**: Синтез настоящего механического щелчка iPod 1G через Web Audio API (без использования сторонних аудиофайлов)[cite: 8].
- **Тумблер HOLD**: Физический переключатель блокировки всех кнопок и колеса в верхней части корпуса[cite: 8, 9].
- **Реальный индикатор батареи**: Синхронизация уровня заряда и статуса зарядки через Battery Status API[cite: 8].
- **Перемотка (Scrubbing) и громкость**: Нажатие центральной кнопки на экране *Now Playing* включает режим посекундной перемотки колесом; обычное вращение колеса на экране плеера плавно регулирует громкость[cite: 8].

### Музыка и библиотека Spotify
- **Spotify Web Playback SDK**: Полноценное воспроизведение музыки прямо в браузере[cite: 6, 8].
- **Полная синхронизация медиатеки**: Плейлисты, сохраненные альбомы, отслеживаемые артисты и все лайкнутые треки (с фоновой догрузкой больших библиотек свыше 50 треков)[cite: 6, 8].
- **Режимы воспроизведения**: Быстрый *Shuffle Songs*, переключение *Shuffle* и *Repeat* (`Off` / `All` / `One`)[cite: 8].

### Раздел Extras и PWA
- **Brick (Game)**: Встроенная классическая игра Арканоид, управляемая вращением колеса Click Wheel[cite: 8].
- **Clock & Sleep Timer**: Классические часы на весь экран и таймер сна (`15m`, `30m`, `60m`), автоматически ставящий плеер на паузу[cite: 8].
- **PWA (Progressive Web App)**: Установка приложения на рабочий стол смартфона (iOS / Android) или ПК в полноэкранном режиме (`Settings -> Install App`)[cite: 8, 9, 10].

## Как добавить собственную тему оформления (HTML + CSS)

Каждая тема в iPodify полностью изолирована в своей папке `src/public/themes/<theme_id>/` и имеет собственный HTML-каркас (`layout.html`), таблицы стилей (`style.css`) и, при необходимости, собственную вёрстку внутренних экранов:

1. Создайте папку темы, например `src/public/themes/vision/`.
2. Создайте внутри неё `layout.html` с вашей разметкой корпуса, сохранив базовые `id` для привязки органов управления (`#screen`, `#screen-content`, `#status-title`, `#click-wheel`, `#btn-center`, `#btn-menu`, `#btn-prev`, `#btn-next`, `#btn-play-pause`, `#hold-switch`).
3. Создайте `style.css` в этой же папке.
4. Зарегистрируйте тему в `src/public/themes/registry.js`:
   ```javascript
   window.IPODIFY_THEMES = [
       {
           id: 'classic',
           name: 'Classic 1G',
           layout: '/themes/classic/layout.html',
           css: null
       },
       {
           id: 'ios26',
           name: 'iOS 26 Glass',
           layout: '/themes/ios26/layout.html',
           css: '/themes/ios26/style.css',
           renderNowPlaying: (ctx) => `...кастомный HTML экрана плеера...`
       }
   ];
